Privacy Policy

Last updated: October 5, 2026

Jira Job Automation

Jira Job Automation is a personal job-search automation application. It is used by the authorized user to manage job opportunities, recruiter responses, application updates, and interview information.

Google User Data

The application requests read-only access to Gmail messages using the Google Gmail API.

Gmail data is accessed only to identify information relevant to job applications, including recruiter responses, application status updates, interview invitations, and related job-search communications.

How Google User Data Is Used

Relevant information identified from Gmail may be used to update the authorized user's private job application tracker.

The application does not use Gmail access to send, modify, or delete email messages.

Data Sharing

Google user data accessed by this application is not sold to third parties and is not used for advertising.

Data Protection

Access credentials and job-tracking information are maintained in private systems controlled by the authorized user.

Access Revocation

The authorized user can revoke the application's Google Account access through their Google Account security settings.
